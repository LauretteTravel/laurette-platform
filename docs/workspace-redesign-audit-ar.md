## Existing — إعادة الاستخدام

Node/SQLite وواجهة JavaScript الحالية؛ RBAC وMFA وmust_change وCSRF؛ overview والطلبات والعملاء والمتابعات والمهام والجرس والتفويضات؛ قسائم وبرامج وتقارير المراحل السابقة؛ الشعار الرسمي public/media/brand/logo.png وصور الوجهات الحالية. لا استبدال للمكدس أو المصادقة أو صفحات الموقع.

overview الحالي يعيد إحصاءات وقائمتي recent وneedsAction محدودتين، لكنه لا يمثل التعريفات المطلوبة لليوم: بعض حساباته UTC أو عمر الطلب بدل موعد المتابعة. سيوضع ملخص يومي واضح داخل مسار overview نفسه مع إبقاء حقوله القديمة؛ لا مسار منافس يؤدي نفس الوظيفة. تُستعمل نطاقات الطلب والمهام الحالية ويُمنع كشف سجل أو عداد دون صلاحية المصدر.

## Change — مقارنة المرجع

المرجع يحتوي Sidebar يمينًا بنحو14% من العرض، Top Bar ثم عملات، Hero سياحي،6 اختصارات،5 مؤشرات، عمل اليوم يمينًا ونشاط يسارًا، ثم6 إجراءات. الواجهة الحالية Sidebar وقسم إحصاءات وجدول دون هذا الترتيب أو الخلفية. ستُحصر الهوية الجديدة في الرئيسية؛ تبقى صفحات CRM والإدارة والقسائم والتقارير بواجهاتها ووظائفها. يكون Sidebar قابلًا للطي على اللوحي وDrawer على الهاتف، وقائمة اليوم بطاقات هاتفية.

## Add — إضافات لازمة فعلًا

- محول بيانات للملخص والعمل اليومي والأحداث الحالية، بأعداد من DB وحدود/صفحات. أسماء وجهات وصور من السجل أو أصول مناسبة، مع بديل عند فقدها؛ لا ادعاء مشاهدة عرض أو اهتمام عميل بلا حدث مصدره.
- بحث بواجهات البحث الموجودة حسب الصلاحية مع حد للنتائج وتأخير للكتابة، وأزرار تنقل وفعل حقيقية. لا تحميل كامل CRM عند فتح اللوحة.
- خدمة صرف منفصلة بعقد مزود واضح JOD مقابل الوحدة الأجنبية؛ بلا مزود أو سعر حي افتراضي. مصدر ووقت وقدم البيانات وآخر قيمة سليمة وبديل يدوي صريح بصلاحية مستقلة ومراجعة وسجل. لا تطبيق هذه الأسعار على الحجوزات أو التقارير المالية. استخدام meta القائم للحفظ لا يحتاج ترحيل مخطط.
- لا مسار مستقل حاليًا لإنشاء عميل أو لعرض كل الحجوزات المستقبلية. يجب ربط «عميل جديد» بإنشاء فعلي واضح أو إضافة صغيرة بنفس قواعد الهوية والنطاق، وعدم تسميته تسجيل عميل إذا كان ينشئ طلبًا خفيًا. مؤشرات الحجوزات القادمة تتطلب تاريخ سفر/إقامة موثوقًا؛ لا يُستنتج الموعد من تاريخ التأكيد.
- خلفية فقط من تكوين المرجع، بلا بطاقات أو نصوص مرسومة؛ عناصر الواجهة حقيقية. المصدر والشعار محفوظان. الطقس اختياري، ولا تُنسخ حرارة/ساعة أو أسعار/أسماء/أرقام المثال إلى الإنتاج.

## Preserve — الحماية والحدود

لا حذف بيانات أو خدمات أو تغيير Authentication أو React أو مشروع منفصل. لا تعديل صفحات الموقع والعروض والقسائم والتقارير إلا ربط صغير لازم. لا تسريب عابر للفروع أو منح ضمني لإدارة العملات. لا دمج أو نشر أو شراء خدمة.

## التحقق

اختبارات نطاق اليوم وعمّان والعضويات والصلاحيات، غياب المصدر/فشله/البيانات القديمة/التعديل اليدوي/التعارض، البحث والإجراءات الحقيقية والفراغ والخطأ. npm test وnpm run smoke؛ قبول متصفح1440×900 ومقارنة المرجع، ولوحي وهاتف ولوحة مفاتيح وحركة مخفّضة. لا إعلان اكتمال قبل حفظ اللقطات وفحصها بصريًا.
