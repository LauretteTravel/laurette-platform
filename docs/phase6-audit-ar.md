# تدقيق ما قبل المرحلة السادسة — الصقل والتسليم

2 نوفمبر 2026، المرجع 8b46ac5 من المرحلة الخامسة، PR17 ما زال مفتوحًا وغير مدمج. التنفيذ فوقه في codex/employee-operations-phase-6؛ لا نشر أو دمج أو تعديل إعداد إنتاجي أو شراء خدمة.

## الموجود وما يُحفظ

218 اختبارًا و27 فحص دخان، مصفوفة تفويض مولدة، قبول متصفح فعلي للقسائم والبرامج والتقارير وPDF عربي، ومراجعة بشرية للنشر. مخطط قاعدة البيانات 8؛ لا حاجة لترحيل في مرحلة الصقل. حماية must_change وMFA وCSRF والنطاق تبقى على الخادم.

## الفجوات المثبتة بالكود

- openDrawer في admin.js يعلن aria-modal دون منع وصول لوحة المفاتيح للخلفية أو إدارة التركيز/اسم النافذة. الإغلاق فقط Escape أو نقرة، وعدة أزرار × بلا تسمية.
- adminRoot عنصر main يحتوي main آخر، وaria-live يحيط بالتطبيق كله؛ تغيير القسم لا يعلن حالة تحميل واضحة ولا يضبط التركيز/aria-current.
- لا فحص وصول آلي أو ميزانية أداء متصفح موثقة. أدوات measure.mjs تقيس زمن fetch وحجم الملفات فقط؛ لا تثبت LCP أو سرعة تفاعل حقيقية.
- /health العام يفيد جاهزية العملية فقط. توجد صحة دورة المواعيد وسجلات إرسال واستيراد ونسخ ترحيلات منفصلة، دون شاشة عمليات خاصة. لا توجد آلية تثبت نسخًا دورية أو استعادة يومية، ولا يصح وصف وجود ملف بأنه استعادة متحققة.
- أسعار الصرف لم تنفذ في المرحلة الخامسة. لا مزود معتمد ولا مصدر أسعار؛ تبقى فجوة معلنة، ولا تدخل أسعار ثابتة أو مفترضة في الحسابات أثناء الصقل.

## نطاق التنفيذ والقبول

1. نافذة جانبية أصلية dialog مع عنوان وتركيز وإرجاعه، رابط تجاوز للتنقل، حالات تحميل/خطأ وتسميات وعلامات تنقل واضحة، تحسين التباين والحركة ضمن هوية لوريت.
2. شاشة صحة للمؤسسة فقط بصلاحية system:health مستقلة وMFA، قراءة دون تشغيل/إعادة محاولة/حذف: مخطط DB، نبض الوظائف، أعداد حالات الإرسال والاستيراد، حالة تمكين الرفع، وجرد محدود لنسخ الترحيلات بلا مسارات/أسماء/أسرار/حمولات عملاء. إعداد التكامل ليس إثبات اتصال حي.
3. قبول متصفح ببيانات مصطنعة: فحص axe وفق قواعد WCAG2 A/AA و2.1/2.2، لوحة مفاتيح وحصر نافذة وتركيز، 390px و200% وحركة مخفّضة، قياسات تنقل/LCP/تفاعل وحجم أصول بميزانيات معلنة. لا ادعاء شهادة WCAG كاملة أو TTI معياري من قياس واحد.
4. تشغيل الاختبارات السابقة ومصفوفة التفويض والدخان وقبول PDF/الاستيراد والفاحص والاتصال المشفر؛ أدلة CI مصطنعة فقط. توثيق التسليم والرجوع والفجوات المتبقية.

مرجع المعايير: [WCAG 2.2](https://www.w3.org/TR/WCAG22/) و[نمط النافذة المشروطة WAI-ARIA](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/). الفحص الآلي والعينة اليدوية لا يثبتان مطابقة كل الصفحات وكل قارئات الشاشة.
