# إصلاح أسماء مستخدمي الموظفين

السبب: كان الخادم يقبل الأحرف اللاتينية فقط، وتعرض الواجهة رسالة غير كافية للمستخدم العربي.

التغيير: قبول العربية والإنجليزية والأرقام والنقطة والشرطة والشرطة السفلية بطول 3–32 حرفًا، مع تطبيع NFC موحد عند الإنشاء والدخول. تُرفض المسافات الداخلية والرموز المخفية واتجاه النص والرموز غير المسموحة، وتبقى الأسماء الإنجليزية القديمة متوافقة. توضح الواجهة القاعدة ومثالًا عربيًا.

لا توجد ترحيلات أو تعديلات على بيانات الحسابات الحالية. الإصلاح مستقل عن المرحلة 1B، ولا يتطلب مفاتيح MFA الخاصة بها.

التحقق المحلي: 105/105 اختبارًا ناجحًا، منها اختبارا القاعدة وتكامل الإنشاء والدخول ومنع التكرار وحماية must_change. فحوص الدخان 27/27 ناجحة، وفحص صياغة admin.js ناجح.

لم يتم الدمج أو النشر. دعم العربية في الإنتاج يتطلب اعتماد ودمج ونشر طلب المراجعة.
