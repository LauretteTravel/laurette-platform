# تدقيق المرحلة الرابعة — إدارة البرامج والعروض

المرجع: القسم 10 من الخطة المعتمدة. أساس العمل: المرحلة الثالثة c121754، على فرع مستقل؛ لا دمج ولا نشر ضمن هذا التسليم.

## الموجود الذي سيُحتفظ به

- جدول programs ومحتواه وروابطه وحقوله المتنوعة وصور الهوية، وصفحات الموقع والبحث والطباعة والتوصيات وطلبات العملاء المرتبطة بالـslug.
- التصنيفات القديمة والخيارات والفنادق ومسار الرحلة والشروط، وصلاحيات الجلسة وmust_change وMFA وCSRF وسجل التدقيق والترحيلات ذات النسخ الاحتياطية.
- العروض المختصرة في offers خدمة مستقلة؛ لن تُنقل أو تُحذف تلقائيًا.

## الفجوات المؤكدة قبل البرمجة

1. CRUD العام يكتب مباشرة في البرامج المنشورة، والجديد منشور افتراضيًا؛ لا نسخة مراجعة منفصلة ولا اعتماد سعر أو منع تعارض تعديل.
2. حذف البرنامج غير المرتبط بطلبات يحذف بياناته. لا أرشيف إصدارات يضمن الاسترجاع.
3. قائمة تصنيفات المحرر ثابتة بأربعة اختيارات؛ لا صلاحية نشر منفصلة، ولا مسؤول/فرع/قسم لملف البرنامج.
4. السعر رقم وعملة وخيارات حرة؛ لا أساس فرد/غرفة أو إشغال أو تكلفة أو صلاحية سعر منظمة، ولا توثيق اعتمادها.
5. لا استيراد PDF/DOCX ولا أصل محفوظ أو مقارنة موثقة بالمصدر. لا يجوز استنتاج ثقة رقمية أو نشر أسعار مستخرجة تلقائيًا.

## ترتيب التنفيذ

1. ترحيل إضافي فقط: مساحة عمل مرتبطة بالبرنامج القديم، تصنيفات قابلة للإدارة، إصدارات ومصادر خاصة وسجل أحداث محفوظ. لا تحديث لصفوف programs أثناء الترحيل، ولا منح صلاحيات تلقائي.
2. محرر فعلي: مسودة → مراجعة → اعتماد بشري → نشر صريح، مع إعادة المراجعة بعد أي تعديل، قفل تعارض بالإصدار، نطاق الفرع/القسم/المسؤول، وأرشفة دون حذف الأصل.
3. أسعار منفصلة حسب العملة والأساس والإشغال، اختيار سعر العرض صراحة، صلاحية العرض وفترة السفر. تحديث الموقع فقط عند النشر المعتمد مع الاحتفاظ بالـslug.
4. استيراد محدود الحجم ومفحوص أمنيًا، استخراج محلي بلا إرسال لطرف ثالث، حفظ الأصل الخاص حتى عند فشل الاستخراج، اقتراحات موسومة غير متحققة مع مواضعها ومقارنة قبل/بعد ومراجعة بشرية. الملفات المصورة لا تُعطى نتيجة OCR وهمية.
5. اختبارات أمان وتكامل وترحيل/استعادة وحالات فشل الاستيراد وتحقق واجهة على بيانات مصطنعة، ثم PR للمراجعة.

## حدود التشغيل

رفع المصادر سيبقى مغلقًا افتراضيًا، مع فشل آمن عند تعطل فحص الفيروسات. لم يُعتمد شراء خدمة فحص جديدة؛ يمكن إدخال النص يدويًا ومراجعته، وتجهيز مسار الملفات واختباره محليًا وفي CI. لا تفعيل إنتاجي أو تغيير أسعار أو نشر ضمن المرحلة الحالية. المرحلة الثالثة اعتماد سابق لازم قبل نشر هذا الفرع المتتابع.
