# Laurette OpenWA service

The OpenWA package is installed here as a separate service. It is not started, paired with a WhatsApp account, or connected to the public Laurette website yet.

Requirements: Node.js 22.21.1 or newer and a persistent server process. Keep WhatsApp session/profile data and API keys private; do not commit them.

OpenWA is an unofficial WhatsApp Web automation project. Pairing a real business number may lead to account restrictions. Continue only with a number you control, and only message customers who opted in.

See the official setup guide before generating the Easy API starter: https://openwa.dev/docs/getting-started/easy-api
